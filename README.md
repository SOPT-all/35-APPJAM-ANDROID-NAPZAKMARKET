## 🕓 Tech Stack
| Title | Content | Purpose |
| ------------ | -------------------------- | --- |
| Architecture | `Clean Architecture` | - 명확한 의존성 관리<br> - 프로젝트의 확장성을 확보 |
| Pattern | `MVVM` | - 효과적인 상태관리 <br> - 모두에게 익숙한 패턴 | 
| UI Framework  | `Jetpack Compose`  | - 직관적이고 명확한 UI 코드 작성 가능 <br> - 코드의 재사용성과 효율 증가 |
| Build Tools  | `Gradle Version Catalog` | - 효율적인 의존성과 플러그인 관리 |
| Dependency Injection | `Hilt`  | - 편하고 효율적인 모듈 간 의존성 관리 |
| Navigation | `Jetpack Navigation`  | - 화면 간 이동 <br> - 화면 간 데이터 전달  |
| Network | `Retrofit2`, `OkHttp`  | - 네트워크 처리 라이브러리 <br> - 타입 안정성 보장  |
| Asynchronous Processing | `Coroutine`, `Flow` | - 동시성 프로그래밍 지원 <br> - 쉬운 사용성과 높은 가독성 제공 |
| Image Processing | `Coil`, `Lottie` | - Coil: 벡엔드 이미지 로딩 라이브러리 <br> - Lottie: 애니메이션 포함 이미지 표시|
| Logging | `Timber` | - 디버깅 때만 로그를 표시 |\
